## 🚀 Ключевые Production-Ready Проекты

* 🧪 **[Elastomeric 1K PU]((https://github.com/czeberyak/elastomeric_1k_pu))** — Цифровой протокол полного цикла R&D для строительного полиуретанового герметика. Каскадный LLM-пайплайн для парсинга спецификаций (TDS) и патентного FTO-анализа (Sika, Dow). Реализована матрица экспериментов (DOE) и генерация синтетических данных с физическим шумом для RSM-оптимизации целевых метрик *in silico*.
* ⚙️ **[Poly-Kinetics (Physics-Informed ML)]((https://github.com/czeberyak/poly-kinetics))** — Гибридный предиктивный инструмент для оценки технологического окна (*pot life*) полиуретановых эластомеров. Интеграция закона Аррениуса в кастомный трансформер Scikit-learn. Точность предсказания $R^2 = 0.9340$.
* 📊 **[Predictive Maintenance (RUL) on NASA Dataset]((https://github.com/czeberyak/industrial-health-index-pdm))** — Алгоритм прогнозирования ресурса подшипников по виброакустической телеметрии. Внедрена кастомная логика (Run-in Mask), автоматически отсекающая первые 100 часов приработки, что радикально снизило количество ложных срабатываний (False Positives).
* 🎅 **[Pismo-deda.ru (GenAI & Full-Stack RAG Architecture)](https://pismo-deda.ru/)** — Коммерческий B2C-сервис генерации персонализированного контента (React / Flask / Firebase). Спроектировал LLM-агента (Gemini 2.5 Flash) с семантическим поиском FAISS и Cross-Encoder ре-ранжированием. Разработал надежную машину состояний для архитектуры *Human-in-the-Loop* — с двухуровневой системой таймаутов, умным роутингом диалогов и синхронизацией флагов Firestore в реальном времени.
