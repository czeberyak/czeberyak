## 🚀 Портфолио: от методологии до production

Коммерческий B2C-сервис генерации персонализированного контента (React / Flask / Firebase), действующий с 2014 года и полностью переработанный в 2025 на новом стеке. Спроектировал LLM-агента (Gemini API) с двухэтапным поиском: семантический retrieval на эмбеддингах (SentenceTransformer) и Cross-Encoder ре-ранжирование, отсеивающее формально похожие, но нерелевантные фрагменты перед генерацией. Human-in-the-Loop: надёжная машина состояний с двухуровневой системой таймаутов, умным роутингом диалогов между AI и оператором и синхронизацией флагов Firestore в реальном времени. Архитектура адаптируема под другие LLM, включая GigaChat.

**🎯 BunkerVision (Computer Vision + Reliability Engineering)** — *тестовое задание, production-grade инженерия*
Мониторинг наполненности бункеров сырья по RTSP-камерам (YOLOv8n-cls, инференс <5 мс на CPU, Top-1 Accuracy >99% на синтетическом датасете, сгенерированном через Albumentations под заводские искажения — пыль, блики, артефакты потока). Модель — не главное в этом кейсе: акцент сделан на промышленной надёжности. Store-and-Forward буфер на SQLite переживает обрыв связи с ERP (1С); tenacity с exponential backoff восстанавливает отправку данных без ручного вмешательства и без "заспамливания" сети; развёрнут как автономная служба Windows (NSSM) с алертами в Telegram. Реальные исторические данные заказчика в рамках тестового задания не предоставлялись — обучение на синтетике, паттерны отказоустойчивости — реальные инженерные решения.

**🔬 Ca(OH)₂ Digital Twin (DWSIM + ML Surrogate)** — *методология, in silico*
Гибридный цифровой двойник непрерывного гашения извести: DWSIM считает строгую термодинамику (энтальпия, теплоёмкость) через Sensitivity Analysis, ML Surrogate (Scikit-learn) в реальном времени предсказывает пиковую температуру и остаточную влажность по паттерну IIoT-данных, SHAP объясняет вклад признаков. Прямое цифровое развитие Soft Sensor, который я строил вручную на «Реагенте» без доступа к подобным инструментам.

**🧪 Elastomeric 1K PU | 🌐 [Live Demo: AI TDS Parser](https://czeberyak-elastomeric-1k-pu.streamlit.app/)** — *методология, in silico*
Цифровой протокол полного цикла R&D для строительного полиуретанового герметика. Каскадный LLM-пайплайн для парсинга спецификаций конкурентов (TDS) и патентного FTO-анализа (реальные патенты Sika, Dow). Box-Behnken DOE сократил матрицу экспериментов с 27 до 15. Оптимизация целевых метрик через RSM на синтетических данных с физическим шумом — реальный лабораторный синтез по полученной матрице — следующий этап.

**🧫 Epoxy Structural Adhesives (Portfolio Case #2) | 🌐 [Live Demo: RSM Tg/LSS Predictor](https://epoxy-structural-ep1.streamlit.app/)** — *методология, in silico*
Второй кейс Materials Informatics — рецептуры двухкомпонентных конструкционных эпоксидных клеев (Epon 828 + IPDA). Стехиометрический калькулятор на открытых TDS-константах и уравнении ДиБенедетто; Box-Behnken DOE (15 точек); квадратичная RSM на синтетических данных с физическим шумом (Tg R² = 0,97, LSS R² = 0,95) и оптимизация по Desirability Function. FTO-анализ патентов (Henkel, 3M, Sika) и лабораторная верификация — следующий этап.

**⚙️ Poly-Kinetics (Physics-Informed ML)** — *методология, гипотетическое ТЗ*
Предиктивный инструмент для оценки технологического окна (pot life) полиуретановых эластомеров на гипотетическом техническом задании. Генератор синтетических данных на основе уравнения Аррениуса + Random Forest: R² = 0,934, MAE = 7,28 мин. Модель восстановила физические параметры (энергию активации, фактор соударений), совпавшие с заложенными в генератор значениями, — подтверждена математическая корректность подхода. Перенос на реальные кинетические данные — следующий шаг.

**📊 Predictive Maintenance (RUL) on NASA Bearing Dataset** — *методология, открытый бенчмарк*
Гибридная система предиктивной аналитики подшипников на трёх уровнях: физический анализ (RMS) для детекции финальной стадии разрушения, статистический PCA Health Index для обнаружения микро-деградации за сотни часов до роста амплитуды вибрации, и классификация Random Forest (Normal / Warning / Degradation / Critical). ML-фильтры (маска приработки первых 100 часов, порог уверенности 80%, 12-часовое сглаживание) обеспечили раннее обнаружение деградации за 500–600 часов до физического разрушения — окно ~25 суток для планового ремонта вместо аварийной остановки.

**🧾 Sverka Aktov (Reconciliation Engine)** — *тестовое задание*
Детерминированный движок сопоставления хозяйственных операций в актах сверки контрагентов. Принципиальное решение: система не «угадывает» первого похожего кандидата, а оценивает пары независимо по номеру/дате/сумме и явно помечает неоднозначные случаи — приоритет объяснимости (explainability) и защиты от ложных срабатываний над слепой точностью.
