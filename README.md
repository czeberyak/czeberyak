### 🚀 Ключевые проекты

* **[Poly-Kinetics (Physics-Informed ML)](#)** — Гибридный предиктивный инструмент для оценки pot life полиуретановых эластомеров. Интеграция физического закона Аррениуса в кастомный трансформер Scikit-learn (Random Forest ансамбль). Успешно восстанавливает скрытые термодинамические параметры системы.
* **[Predictive Maintenance (RUL) on NASA Dataset](#)** — Модель прогнозирования ресурса подшипников по виброакустической телеметрии. Внедрена кастомная логика (Run-in Mask), исключающая первые 100 часов работы (этап приработки), что радикально снизило количество ложных срабатываний (False Positives).
* **[Industrial-Health-Index](#)** — Модель кластеризации и поиска аномалий (Unsupervised Learning) для определения индекса деградации оборудования методом PCA на сильно зашумленных данных.
* **[Production-Ready API (Data Lineage)](#)** — Коммерческий микросервис на Flask с интеграцией LLM, векторным поиском и полным аудитом изменения данных (Human-in-the-loop архитектура).
